# M0 — Foundation and Governance

- **Status:** In progress
- **Repos:** `goldseats-docs`, `goldseats-api`, `goldseats-web`
- **Depends on:** nothing
- **Blocks:** everything

> **Done when:** both code repos have green CI (lint, typecheck, test, build) and a protected
> `main`.

---

## Goal

Build the container before pouring anything into it. At the end of M0 there is a GitHub org
with three public repos, a protected `main` in each, a CI skeleton that actually runs, and the
complete documentation set that everything after this references.

No product code ships in M0. That's the point — the governance and conventions exist before
there's code to argue about, so the first real PR lands into a working process instead of
inventing one.

---

## Scope

- GitHub organisation, three **public** repos: `goldseats-web`, `goldseats-api`,
  `goldseats-docs`
- Branch protection rulesets on `main` in all three
- CI workflow skeletons: `lint`, `typecheck`, `test`, `build`
- Minimal runnable skeletons in both code repos — enough for CI to have something real to run
- The full `goldseats-docs` content set

- `.env.example` in both code repos

- Database models and migrations — [M1](M1.md)

  [M9](M9.md).

## Risks

| Risk | Likelihood | Mitigation |
| --- | --- | --- |
| Org name changes after docs are written | Medium | Docs use `goldseats` consistently; a single find-and-replace fixes it. Deliberately not scattered through prose. |
| Branch protection configured but not actually enforcing | Medium | Explicitly test it by attempting a direct push to `main` |
| CI skeleton passes trivially and gives false confidence | High | Each job runs a real check on real code. A `test` job with no tests is worse than no `test` job. |
| Docs written and then ignored | High | They're referenced from the PR template and the definition of done, so they're in the path of every PR |
| A secret committed in the first push | Low, catastrophic | `gitleaks` plus push protection plus pre-commit, all before the first push |
| Over-investing in governance before any product exists | Medium | M0 is bounded: skeletons only, no features. If M0 takes more than a week, cut docs depth, not CI. |

- **Status:** Not started
- **Repos:** `goldseats-api`, `goldseats-web`
- **Depends on:** [M2](M2.md), [M3](M3.md)
- **Blocks:** [M8](M8.md)

> **Done when:** a film page shows a multi-source timeline plus nearby showtimes grouped by
> format.

---

## Goal

Build the page that makes GoldSeats worth visiting for a film you're already interested in.
Everything about a film, from every source we have, as an expandable chronological timeline —
plus where it's playing near you, and an honest opinion about the best way to see it.

The timeline is the differentiator. Every other film site shows you a synopsis and a trailer.
Ours shows you the whole arc: when it was announced, when it was cast, when the trailer
dropped, how it went at festivals, what the reviews said, when it opened. One page, many
sources, in order.

---

## Scope

- `GET /v1/films/{film_id}/timeline` — aggregated `film_timeline_events`, grouped and ranked
- Timeline event ingestion beyond TMDB: festival dates, review aggregate snapshots, trailers
- `GET /v1/films/{film_id}/showtimes` (or `/v1/showtimes?film_id=`) with proximity
- Format ranking service in `app/domain/formats.py`
- Web route `/films/[filmId]`
- `FilmTimeline` — collapsed by default, expandable, source-attributed
- `NearbyShowtimes` — grouped by theatre, then by format
- `FormatRanking` — the "best way to experience" panel
- Coverage honesty: what we show for a film playing at a theatre we haven't seeded

## Out of scope

- Seat selection and recommendations — [M5](M5.md)
- 3D preview — [M6](M6.md)
- Follow button and notifications — [M8](M8.md), though the button's slot is designed here
- News aggregation as a source — [M8](M8.md). M4's timeline uses TMDB, festival, and review
  events; `news` events arrive later and the timeline is built to absorb them.
- User reviews or ratings of our own. Never, per
  [`../roadmap.md`](../roadmap.md#what-were-explicitly-not-building).

## Issue breakdown

### API — timeline

- [ ] `GET /v1/films/{film_id}/timeline` returning events ordered by `occurred_at`, with
      `event_type`, `source`, `source_name`, `url`, `importance`, `precision`
- [ ] `?since=` and `?event_types=` filters
- [ ] `?importance_min=` so the client can request the collapsed set in one call
- [ ] Deduplicate across sources on `(source, external_id)` and on near-identical
      `(title, occurred_at)` pairs
- [ ] Ingest `festival` events — premieres and festival screenings from TMDB and manual entry
- [ ] Ingest `review` events — aggregate score snapshots with attribution, **not** full review
      text
- [ ] Ingest `award` and `casting` events where TMDB provides them
- [ ] Assign `importance` by heuristic: release and trailer high, casting low, and document
      the heuristic
- [ ] Set `precision` correctly — a lot of historical film data is month-accurate at best
- [ ] Cache: 15 minutes, tagged

### API — showtimes and formats

- [ ] `GET /v1/showtimes?film_id=&near=lat,lng&radius_km=&date=` returning showtimes grouped by
      theatre
- [ ] Each showtime embeds formats, presentation language, subtitle language, accessibility
      flags, and booking links
- [ ] `app/domain/formats.py` — rank available formats for a film using
      `showtime_formats.quality_rank`
- [ ] Ranking returns a **reason per format**, not just an order. "IMAX at 1.43:1 shows more
      of the frame" is the product; a sorted list isn't.
- [ ] Handle the case where the best format isn't playing nearby — say so rather than silently
      recommending the second best
- [ ] Response includes whether the film was shot or finished for a given format where we know
      it
- [ ] Query-count tests; eager-load everything serialised

### Web — the page

- [ ] `/films/[filmId]` server component with parallel fetches for film, timeline, showtimes
- [ ] Hero: backdrop, poster, title in `films.title` with `lang`, runtime, certification,
      primary release date
- [ ] Metadata and Open Graph tags per film — this page is our main SEO surface
- [ ] `loading.tsx` skeleton matching the real layout
- [ ] `error.tsx` with human copy
- [ ] A slot for the [M8](M8.md) follow button, present but flag-gated

### Web — `FilmTimeline`

- [ ] Vertical timeline, newest or oldest first (pick one and be consistent), grouped by year
- [ ] Collapsed by default to high-importance events, with "show all N events"
- [ ] Each event: date rendered at its `precision`, type icon **plus** a text type label,
      title, body, source attribution, outbound link
- [ ] Expandable event bodies, as `<details>`/`<summary>` or an equivalent accessible
      disclosure
- [ ] Trailer events embed a thumbnail linking out; **no autoplay**
- [ ] Source attribution is visible on every event, not hidden behind a hover
- [ ] Keyboard navigable; expansion state announced
- [ ] `prefers-reduced-motion` disables expand/collapse animation

### Web — `NearbyShowtimes` and `FormatRanking`

- [ ] Location: use the user's `preferred_city` when logged in, otherwise ask for geolocation
      permission, otherwise default to Toronto with a visible city picker
- [ ] Group by theatre, then by format within each theatre
- [ ] Times rendered from `starts_at_local` with a `<time datetime>` machine value
- [ ] Show presentation language and subtitle language on each showtime — this matters
      enormously in a bilingual market and most sites bury it
- [ ] Accessibility flags (descriptive audio, captioning) shown on each showtime
- [ ] Sold-out and past showtimes visually and textually distinct, not just dimmed
- [ ] `FormatRanking` panel: ordered formats, each with its reason, marking which are playing
      nearby
- [ ] Each showtime links forward to the [M5](M5.md) seat map route, flag-gated until M5 ships
- [ ] **Honest coverage state:** when a film is playing nearby at theatres we haven't seeded,
      say "we don't have seat data for this theatre yet" rather than omitting it silently or
      pretending

### Testing

- [ ] Playwright: showtimes grouped by format, format ranking visible
- [ ] axe clean on the film detail page
- [ ] Lighthouse ≥ 90 on a film page with a long timeline
- [ ] Vitest: timeline collapse/expand, `precision` rendering, `FormatRanking` ordering

## Risks

| Risk | Likelihood | Mitigation |
| --- | --- | --- |
| Timeline is sparse and unimpressive for most films | High | Set `importance` well so the collapsed view is dense even when the full history is thin. A four-event timeline that reads well beats a twenty-event one that doesn't. |
| Timeline is overwhelming for a major film | Medium | Collapsed by default, importance-ranked, grouped by year |
| Reviews raise copyright questions | Medium | Aggregate scores and headline links only. **Never full review text.** See [`../../legal/data-sources-policy.md`](../../legal/data-sources-policy.md). |
| Format ranking is contested | Certain | It's an editorial opinion; present it as one, with reasons, and store `quality_rank` as reviewable data |
| Geolocation permission denied, so "nearby" is broken | High | Fall back to `preferred_city`, then to Toronto with a visible city picker. Never a blank panel. |
| Page is slow with timeline plus showtimes plus formats | Medium | Parallel fetches, eager loading, query-count tests, Lighthouse as a blocking check |
| Coverage gaps make the page feel broken | High | Explicit, designed "we don't have this theatre yet" state. This is a design problem, not an error. |
| Timeline deduplication merges genuinely distinct events | Medium | Conservative matching; prefer a visible duplicate over a hidden event |

## Done when

**A film page shows a multi-source timeline plus nearby showtimes grouped by format.**

Verified by opening `/films/<slug>` for a seeded, currently-playing film and seeing:

- A timeline with events from **at least two distinct `source` values**, each attributed and
  linked
- The timeline collapsed by default and expandable to the full history
- Nearby showtimes grouped by theatre and then by format, with correct local times and
  language information
- A "best way to experience" panel ranking the available formats **with reasons**
- Every seeded showtime linking forward to its seat map
